A. MISE EN LIGNE (une seule fois, dans le dossier ocezam77)
 1. npx wrangler login
 2. npx wrangler d1 create ocezam77
    -> copier le database_id affiché dans wrangler.toml (remplace REMPLACER-PAR-L-ID-D1)
 3. npx wrangler pages project create ocezam77 --production-branch main
 4. npx wrangler pages secret put ADMIN_TOKEN --project-name ocezam77   (mot de passe de l'admin, code long)
 5. npx wrangler pages deploy public --project-name ocezam77
 6. Tester https://ocezam77.pages.dev puis /admin.html
    Les tables de la base se créent toutes seules (aucun fichier SQL à exécuter).

B. DOMAINE 77.ocezam.com
 - Cloudflare > Workers & Pages > ocezam77 > Custom domains > ajouter 77.ocezam.com
 - Si ocezam.com est géré par Cloudflare : le CNAME est créé tout seul.
 - Sinon, chez le gestionnaire DNS : CNAME  77  ->  ocezam77.pages.dev
 - Ne pas toucher aux autres enregistrements de ocezam.com (site 95 et e-mails inchangés).
